# CLAUDE.md — Design Portfolio

Public portfolio of graphic and web design work; `index.html` is the GitHub Pages gallery.
Read [docs/HISTORY.md](docs/HISTORY.md) first and add a dated entry after each session.

## Rules
- README, docs and commit messages in English.
- Never publish personal data: blur contact details (phone, e-mail, address, tax/register numbers)
  on stationery and similar work.
- Client work goes to the private `design-portfolio-private` repo until the client approves
  publication.
- No third-party photos except in website screenshots whose sites credit them.
- New work: add a numbered folder, a section in `index.html` and a row in `README.md`; keep images
  at most ~2000 px and include SVG originals where they exist.
